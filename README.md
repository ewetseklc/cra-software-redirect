# cra.software redirect

Tiny GitHub Pages site that sends visitors from cra.software to https://periwynk.com, keeping the path, query string and hash.

The main Periwynk site lives in [chisenga-risk-automation](https://github.com/ewetseklc/chisenga-risk-automation). Do not change Name.com DNS for cra.software; the existing A and www records already point at GitHub Pages.
